# 素材・共通版・由来

## キャラクター

`shared\characters` は既存の制作素材から共通化したキャラクター定義です。
描画はSVG／DOMとGSAPによるフラットなアニメーションです。今回の共通プロジェクトは3Dレンダラーではありません。
別のモデルセットや本格的な3D制作はSHU WORKSの別プロジェクトとして扱えます。

| キー | キャラクター |
|---|---|
| `tanaka` | 田中 |
| `suzuki` | 鈴木 |
| `yamada` | 山田部長 |
| `sato` | 佐藤 |
| `kobayashi` | 小林 |
| `ito` | 伊藤 |

ロボットは `blue`、`red`、`green`、`yellow`、`purple`、`teal` の色バリエーションがあり、カラーコード指定もできます。
表情／ポーズの見本は `catalog\characters.html` を参照してください。

リグは `idle(tl, start, end)`、`wave(tl, t, { s, times, keep })`、
`pose(tl, t, name, side, duration)`、`expr(tl, t, name)` などの既存APIを維持しています。
人の表情には `normal`、`smile`、`happy`、`surprised`、`worried`、`serious`、`deadpan`、`calm`、
ロボットには `normal`、`smile`、`happy`、`surprised`、`think`、`error` などがあります。
利用可能な動きの詳細は `shared\characters\rig.js` 内の定義を参照してください。

## 小物

`shared\props\props.js` に共通小物、`props_harness.js` にハーネス関連の追加小物があります。
見本は `catalog\props.html` の全4ページです。

| ページ | 内容 |
|---|---|
| 1 | メモ、台本、PC、机、時計、カメラ、箱、音声合成マシンなど |
| 2 | ブラウザ窓、コード、タイムライン、吹き出し、矢印など |
| 3 | 手に持たせる例とキャラクターに対する縮尺 |
| 4 | ハーネス、ゲート、検査機、カード、Copilot名札など |

`Props.create(name, opts)` は `el`、`parts`、`points`、`k`、`place(x,y)` などを持つ小物を返します。
`Props.info(name, opts)` で原点に対する外接矩形などを取得できます。
手持ち小物は `Props.hand(name, character, 'R'|'L', opts)` を使い、
返されたオブジェクトの `.pose(tl, t, 'present'|'raise'|...)` で手と小物を連動させます。
右手（`'R'`）では文字が反転しないよう絵を左右反転せず、左手と鏡像の位置に置きます。
そのため握る位置（`grip`）が手から離れる小物は、定義の `hold.gripInHand: true`（または `opts.gripInHand`）で
絵の向きを保ったまま `grip` を手の中に置きます。虫めがねは1.4.3からこの指定で、左右どちらの手でもレンズは右上に傾きます。
`Props.anim` に時計、メーター、機械などのアニメーションがあります。

## 音楽・効果音

`shared\audio\theme.py` は既存作品の共通メロディー／コード進行、
`instruments.py` は基本楽器、`extra_instruments.py` はピアノ／パッドです。
`music.py` は今回新しく作成した、作品全体の固定BPMで演奏し、プリセットで楽器編成を変える生成器です。
映像シーンの境界では曲の拍・コード・余韻をリセットしません。
既存作品の完成BGM WAVを流用しているわけではありません。

`sfx.py` は13種の合成効果音を定義しています。
利用できる名前は `BANK` の定義と、生成された `build\project.js` の `sfxNames` にあります。
`soundEffectSeed` と音名からseedを決めるため、使用する音の追加や呼び出し順で他の音色が変わりません。
音声DSP、音量計測、True Peakリミッターは既存の共通定義を独立モジュール化しています。

既存制作素材由来であることは、第三者の商標や全素材への包括的な権利保証を意味しません。
外部に配布する際は提供素材・フォント・各ライブラリの利用条件を確認してください。
Copilotの素材を使うことは、Microsoft／GitHubとの公式な関係や推奨を意味しません。
本プロジェクトのMITライセンスと、ロゴ・第三者素材の別条件はルートの `NOTICE.md` を参照してください。
SHU Worksロゴの使用は任意で、商用・非商用の制作物で利用できます。

共通化に伴う変更は、フォント／アイコンの相対参照、字幕の安全域、共通stage、
効果音seed、工程・設定の独立化です。1.1.0ではBGMの連続演奏と試作動画の動きを改善し、
1.3.0ではDesigner生成のロゴと、その透過PNG・生成記録を追加しています。
共通化元の作品のソース・素材・成果物は変更していません。

1.4.2では制作環境をPython 3.14／Node 24 LTSへ更新し、セットアップに事前検査を追加しています。
Playwright Core 1.63.0を採用し、NumPy 2.5.3・キャラクター・小物・GSAP・音楽定義は変更していません。
既存作品の `sharedVersion` は変更せず、新作のひな型だけを1.4.2へ更新しています。

1.4.3では、右手に持たせた虫めがねの柄が手から離れて浮く不具合を修正しました。
`Props.hand` に `hold.gripInHand`／`opts.gripInHand` を追加し、虫めがねだけに適用しています（右手ではレンズが体の外側へ傾きます）。
全手持ち小物を左右・姿勢別に確認し、他の小物の見え方は変更していません。
右手の虫めがねを `grip` の符号反転で回避していた作品は、1.4.3へ更新する際にその回避を外してください（外すと同じ絵になります）。

## 共通部分を変更するとき

1. 1作品だけの演出・小物・音楽アレンジは、まずその作品内に置きます。
2. 複数作品で使うことになった素材を `shared` に追加し、見本とガイドを更新します。
3. 既存作品の見え方やAPIが変わる修正では `office-cast.json` と `package.json` の版を更新します。
4. 作品側の `sharedVersion` は自動更新せず、影響を確認してから変更します。
5. テスト、全ビルド、静止画と音声の確認後、その共通版を保存します。

版の不一致検出は、自動で過去版を取得する仕組みではありません。
確定した作品を長期再現するには、対応する共通素材・ソース・依存版と音声WAVの保存が必要です。
共通化元の作品の専用演出や個別クリップは、この制作基盤に含めていません。

## GitHub Copilotの名札

共通版1.4.0から `Props.create('copilotBadge')` は「GitHub Copilot」の文字だけの名札です。
アイコンの取得やクラウド接続は不要で、素材一覧の全ページもアイコンなしで動作します。
GitHub CopilotのSVGは同梱しません。ローカルに残っている旧素材も自動では読み込みません。

アイコンを使う場合は各利用者が提供元から取得し、利用条件を確認してください。
例えば作品の `src\assets\copilot.svg` に置き、`href` を明示して使います。
キャラクターや小物の共通定義に画像データを埋め込む必要はありません。

```javascript
const href = 'assets/copilot.svg';
K.preload.push(href);
const badge = K.prop('copilotBadge', { href }, 1400, 400, layer);
K.pop(badge.el, K.S('s0').start + 0.5);
```

`K.preload` に指定すると、画像の読み込み・decodeが失敗した場合はレンダーを停止します。
標準の名札は画像が欠落したときの代用品ではなく、最初から画像を指定しない明示的な表示モードです。
指定した画像の取得・配布条件は利用者側で管理してください。
`shared\brand\copilot-icon-black.svg` はGitから除外しています。

## SHU Worksのロゴとエンディング

`shared\brand\shu-works-logo.png` が暗い背景用、`shu-works-logo-ink.png` が明るい背景用です。
両方とも **1321×444、RGBA形式の透過PNG** で、同じ輪郭・アルファを使います。
ロゴの表示表記は **SHU Works**、設定・クレジットのブランド名は従来どおり **SHU WORKS** です。

今回の案は、二つの曲面を向かい合わせた抽象マークと、太さに対比のある細身のワードマークです。
先端アート／モーションスタジオのような、単色・余白・輪郭による印象を狙っています。
Designerで生成した文字をそのまま画像として使い、Inter等で打ち直してはいません。
特定のフォントの使用や商標の独自性を保証するものではなく、外部展開時は利用条件・権利を別途確認してください。
再生時には画像生成サービスやフォントへの接続は不要です。

### 原画・生成記録・透過処理

生成原画は `shared\brand\sources\shu-works-designer-20261009-142928.png`（1536×1024、RGB）です。
同名のJSONに生成サービス、日付、処理方法を保存しています。生成プロンプトは同梱しません。
**原画は透過ではありません。** PNGという拡張子だけで透過したと判断しないでください。

`tools\prepare_shu_logo.py` は、この原画のほぼ白い背景と暗い単色インクに合わせた処理です。
輝度244以上を透明、22以下を不透明、その間を連続したアルファに変換し、
暗い背景用は温かい白、明るい背景用はインク色に揃えて24pxの余白付きで切り出します。
白背景の色をRGBに残さず、文字の穴と輪郭の半透明を保つため、暗い背景で白い縁が出るのを防ぎます。
写真、多色、白いロゴ、複雑な背景の一般的な切り抜きには流用しないでください。

```powershell
.\.venv\Scripts\python.exe .\tools\prepare_shu_logo.py
```

処理済みPNGも保存するため、通常の動画ビルドでは再生成しません。
原画・処理スクリプト・PNGはmanifestのハッシュ記録に含まれます。
生成画像は背景や表記が意図どおりとは限らないため、原画の文字・形と透過後の暗色／明色背景を確認してください。
旧 `shu-works-logo.svg`／`shu-works-logo-ink.svg` は検討履歴として残しますが、現行の標準素材ではありません。

### 配置と演出

縦横比や字間を変えず、ロゴの周囲にはマーク幅の半分を目安に余白を取ります。
1920×1080の動画では幅1120pxで中央に配置し、原寸以上には拡大しません。
今回のPNGではマークと文字の間の空白が横幅23%付近にあります。
`tests\fixtures\motion.js` の分割表示はそこを境にしています。他の画像に差し替える場合は分割位置・縦横比を実画像に合わせ、
文字が欠けたり二重になったりしないことを確認します。

例えば4.5秒のエンディングで、マーク、ワードマークの順に約1.6秒で静かに現し、
完成したロゴを約2.9秒そのまま読ませ、最終フレームにも残せます。
BGMは前の場面から続け、終端でのみフェードします。
画像の分割表示とseekの技術例は `tests\fixtures\motion.js` にあります。
これはテスト専用の短い例で、完成作品・ナレーション・実際の試作動画は同梱しません。
